# 🥔 Cautious Potato — Проект "Союз AI"

Добро пожаловать в официальный репозиторий проекта **Союз AI** (кодовое название для маскировки: *Cautious Potato*). 

Это локальный высокоинтеллектуальный ИИ-ассистент, упакованный в красивое десктопное окно. Система работает полностью автономно на процессоре (CPU) и умеет разделять логику рассуждений и итоговый вежливый ответ.

## ✨ Особенности системы
* 🧠 **Прозрачное мышление**: Отдельное окно отображает лог мыслей модели внутри тегов `<think>`.
* 🤵 **Высокая культура общения**: Робот общается строго вежливо, уважительно и на "Вы".
* 💻 **Локальный инференс**: Работает без видеокарты через `llama-cpp-python`.
* 🎨 **Современный UI**: Графический интерфейс на базе `CustomTkinter` с автоматической поддержкой темной темы ОС.

## 📦 Быстрый старт

1. Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

2. Запустите файл приложения:
```bash
python app_window.py
```
